Install

npm — bundler projects (Vite, Next, Astro, Webpack)

npm install @cosmictraveler002/anim-kit
import { smoothScroll, lineReveal } from "@cosmictraveler002/anim-kit";
import "@cosmictraveler002/anim-kit/styles"; // companion stylesheet (optional)

CDN — no build step (version-pinned)

Import-map entries match specifiers literally, so GSAP subpaths are listed one by one — one shared gsap then serves anim-kit and the rest of your page. Other shapes (standalone bundle, +esm) are spelled out in every copy prompt.

Stuck on the loader? Check the console first: a SyntaxError — does not provide an export named ‘X’ means the CDN @version pin is older than the code importing it. Bump every CDN URL to the same version together and reload — never patch a copied demo by hand, regenerate it (npm run sync:live).

Initialisation process

  1. Load the package — npm import or the pinned CDN map above. The companion CSS ships resting states, mask classes and the pure-CSS pieces; the motion itself is 100% JS.
  2. Create smooth scroll first — smoothScroll() installs the Lenis proxy before ScrollTrigger measures anything; every scroll effect syncs through it.
  3. Create effects after the markup exists — each effect self-initialises GSAP (plugins and studio eases register once), so calls only need their target elements in the DOM.
  4. Keep every destroy function — each call returns a teardown; collect them in an array.
  5. Tear down on exit — on pagehide (or before an SPA route swap) destroy the effects, then the scroller.
  6. Reduced motion is automatic — every effect runs through a guard that skips motion under prefers-reduced-motion; opt back in per call with force: true.
